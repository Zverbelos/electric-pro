Подбор автомата и кабеля

Расчёт по ПУЭ для медного кабеля при прокладке в стене/трубе. Для алюминия — сечение на ступень выше.

Падение напряжения

Норма по ПУЭ: до 5% для силовых линий, до 3% для освещения.

Модули на DIN-рейке

1 модуль = 17,5 мм. Стандартные рейки: 12 / 18 / 24 / 36 модулей.

Подбор УЗО / дифзащиты

УЗО на 30 мА — для защиты людей. Противопожарное 100–300 мА ставится на вводе выше по схеме (селективность).

Расчёт заземляющего устройства

Формула: R = ρ/(2πL) × ln(4L/d), где d ≈ 0,02 м. С учётом экранирования группы η ≈ 0,75–0,85.

Ток короткого замыкания (проверка автомата)

Упрощённый расчёт петли «фаза-ноль». Реальное Iкз может быть ниже из-за переходных сопротивлений (учитываем Zтр ≈ 0,05 Ом).

Расчёт освещения

Упрощённый метод. Для точного расчёта нужен коэффициент использования, отражения, КСС светильников.
